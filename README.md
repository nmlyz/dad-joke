dad-joke is a tiny program that writes one dad joke to a file: a father asks his son to pass the butter, and the son refuses — he doesn't spread gossip at the dinner table.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
